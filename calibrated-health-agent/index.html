Calibrated Health Agent

A personal health agent that keeps score.

Calibrated Health Agent is a personal, single-user project by Karthick Balaje Gopalakrishnan Elango. It reads the owner's own wearable data from the Google Health API and the owner's own daily journal (a Google Form), then makes daily probabilistic forecasts of how the owner will feel and scores them against simple baselines. Every number the agent reports comes with the code that computed it.

  • Read-only: the app never writes, edits or deletes any Google Health or Google Forms data.
  • Personal use only: it is not offered to other users.
  • Data stays in the owner's own Google Cloud project.
