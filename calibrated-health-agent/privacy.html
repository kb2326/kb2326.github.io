Privacy Policy

Calibrated Health Agent · Last updated 21 October 2026

Who this app is for

Calibrated Health Agent is a personal, single-user application operated by Karthick Balaje Gopalakrishnan Elango for his own use. It is not offered to the public.

What data it accesses

With the user's explicit consent through Google sign-in, the app requests read-only access to:

  • Google Health API data: activity and fitness, sleep, health metrics and measurements, profile and settings.
  • Responses to the user's own daily journal Google Form.

The app never creates, modifies or deletes any Google Health or Google Forms data.

How the data is used

The data is used only to provide the app's features to the same user: storing a personal history, computing statistics and daily forecasts, and scoring those forecasts against the user's own journal.

Where the data is stored

Data is stored in the user's own private Google Cloud project and on the user's own computer. Access is restricted to the user and to service identities that run the app's scheduled sync.

Sharing

The data is not sold, shared with, or transferred to any third party, and is not used for advertising. Any publicly shared results are aggregate statistics or synthetic data and contain no raw personal data.

Limited Use

Calibrated Health Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The user can revoke access at any time at myaccount.google.com/permissions and can delete the stored data by deleting it from their Google Cloud project and computer.

Not medical advice

The app describes the user's own data. It is not a medical device and does not provide diagnosis or medical advice.
